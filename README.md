# AstroLens · AI 天文科普互动展项

> 用一句话提问，让星尘为你重构一颗天体。

AstroLens 是一个面向科技馆、校园科普与线上展陈场景的 **AI Native Web 应用**。
观众用语音或文字提出天文问题，系统通过 RAG 检索本地天文知识库，
由大模型判断应当演绎的天体形态并**通过 Function Calling 直接驱动 3D 粒子引擎**，
把答案"演"出来——问黑洞，星尘塌缩成吸积盘；问超新星，粒子向外爆散。

同时提供**无摄像头的鼠标操控**与**本地知识库降级模式**，保证任何设备上都能演示。

---

## 一、核心功能

| 模块 | 能力 |
|---|---|
| AI 问答 | 大模型流式回答，逐字渲染，支持多轮上下文 |
| RAG 检索 | 中文二元组 + TF-IDF + 余弦相似度，全部在浏览器内完成，回答附带来源标注 |
| Agent 工具调用 | `set_morph` / `set_camera` / `trigger_effect` 三个工具，把语义映射为 3D 动作 |
| 粒子演绎 | 7 种形态实时形变：恒星、黑洞、超新星、涡旋星系、星云、行星环、时空涡旋 |
| 手势交互 | MediaPipe HandLandmarker 双手识别，倾斜环绕 / 握拳推拉 / V 手势脉冲 / 双手缩放与时空扭曲 |
| 语音输入 | Web Speech API，无需额外密钥 |
| 程序化音频 | Web Audio 合成星际氛围 BGM 与 12 种交互音效，无外部音频文件 |
| 降级策略 | 无模型 → 本地知识库；无摄像头 → 鼠标拖拽 + 滚轮；无 GPU → CPU 推理 |

## 三、快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 配置模型（可选）

未配置时应用仍可完整运行，只是问答会使用本地知识库模式。

```bash
cp .env.example .env
```

编辑 `.env`：

```ini
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_API_KEY=sk-xxxxxxxxxxxxxxxx
```

> 密钥仅在服务端使用。浏览器请求的是同源地址 `/api/llm/*`，
> 由 Vite（开发）或 `server/proxy.mjs`（生产）注入 `Authorization` 头，
> **不会出现在前端产物或仓库中**。

### 3. 启动开发环境

```bash
npm run dev
```

浏览器打开 `http://localhost:5173`，点击「进入星图」即可。
首次进入后点击左下角「开启手势识别」授权摄像头。

### 4. 生产构建与演示

```bash
npm run build
LLM_BASE_URL=https://api.deepseek.com/v1 LLM_API_KEY=sk-xxx node server/proxy.mjs
```

访问 `http://localhost:8080`。

### 可用脚本

| 命令 | 说明 |
|---|---|
| `npm run dev` | 启动开发服务器 |
| `npm run build` | 类型检查 + 生产构建 |
| `npm run preview` | 预览构建产物 |
| `npm run serve` | 启动生产演示服务器（含 LLM 代理） |
| `npm run typecheck` | 仅执行 TypeScript 类型检查 |

## 四、AI 技术方案

### 4.1 大模型集成

采用 OpenAI 兼容协议，可对接 DeepSeek、通义千问、Moonshot 等任意兼容服务。
对话使用 **SSE 流式响应**，前端逐 token 渲染，配合"思考中"状态与错误边界，
避免长时间白屏。

### 4.2 RAG 检索

- **切分策略**：中文按二元组（bigram）切分并过滤口语停用词，英文按单词切分
- **加权**：TF-IDF + 标题/别名命中加权
- **融合**：Top-3 命中结果拼装为结构化上下文注入提示词，并在回答下方展示来源标签
- **取舍**：未引入向量库与 Embedding API，检索完全本地化，零延迟、零调用成本，可离线运行

### 4.3 Agent 与工具调用

模型通过 Function Calling 主动调用三个工具：

| 工具 | 作用 |
|---|---|
| `set_morph(shape)` | 切换粒子形态以匹配讲解对象 |
| `set_camera(distance)` | 调整观察距离 |
| `trigger_effect(effect)` | 触发脉冲 / 时空扭曲 |

执行结果以 `tool` 消息回传给模型，模型再生成面向观众的讲解，
形成"理解 → 决策 → 执行 → 解释"的闭环。
若模型未主动切换形态，系统按检索结果兜底，保证画面与内容始终相关。

### 4.4 多模态

- **视觉**：MediaPipe HandLandmarker 双手 21 关键点，本地 WASM + GPU 推理
- **语音**：Web Speech API 中文识别
- **文本**：常规输入
- **输出**：3D 形变 + 程序化音频 + 文字，三种通道同步反馈

### 4.5 AI 安全与可控性

| 层面 | 措施 |
|---|---|
| 输入 | 控制字符清洗、500 字截断、危险内容模式拦截、脚本注入过滤 |
| 提示词 | 系统提示限定天文主题、字数上限、禁止编造数据、禁止暴露内部结构 |
| 输出 | 标签剥离、长度截断、空行压缩 |
| 故障 | 超时 30s 中断；鉴权/限流/服务异常分类提示；任一失败自动降级本地知识库 |
| 密钥 | 仅存在于服务端环境变量；`.env` 已加入 `.gitignore` |

## 五、性能优化

- **自定义 Shader**：粒子着色在 GPU 完成，逐粒子色相与柔边光点无需贴图
- **形态预计算**：切形态时只重算目标坐标，渲染循环仅做线性插值，避免每帧三角函数
- **按需加载**：Three.js 与 MediaPipe 分别拆分为独立 chunk，首屏不加载手势模块
- **本地资源**：WASM 与模型全部自托管，不依赖 CDN，弱网环境可稳定运行
- **渲染预算**：单次 Bloom 后期、`depthWrite: false` 的加色混合、DPR 上限 2

## 六、创新点

1. **语义到形体的直接映射**：不是"AI 聊天 + 3D 装饰"，而是让模型通过工具调用接管视觉叙事，
   回答内容与画面形态一一对应。
2. **可解释的科普**：每个回答都标注知识来源，观众知道"这句话从哪来"。
3. **三重降级不中断**：无模型、无摄像头、无网络三种情况都有可用路径，适合真实展陈环境。
4. **零素材依赖**：所有视觉与音频均由代码程序化生成，无版权风险，包体极小。
